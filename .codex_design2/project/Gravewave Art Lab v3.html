How this lands in the codebase

One impact bus Every damage event in Enemy.takeDamage emits a single Game.onImpact({x,y,kind,dmg,crit,resist,fatal}). The impact bus dispatches the right hit-burst + camera shake + damage number — keeps the call site simple.
Shake table 4 named amplitudes (light/medium/heavy/catastrophic). Ultimates fire heavy or catastrophic. Crits add medium on top. The screen-space transform is applied once per frame in Renderer.draw so every system inherits it.
Telegraph windows Boss spawn = 600ms ground-crack pre-roll. Meteor = 600ms target shadow. Wave spawn = 400ms per spawn site. All read from the same Telegraph particle pool so they're cheap.
Specs are diegetic Fireball's Hydra spawns an actual Hydra head sprite that lasts 6s. Meteor spec swaps the cast for a top-down meteor — same telegraph as T3, scaled down. Player sees what the build is doing.
Frost / Shock layers Snow Storm and Storm Cloud both lay flat on the ground. Snow accumulates a faint frost overlay; cloud leaves persistent scorch marks. Status runes from v2 still apply on top — they read individually because they rotate at distinct rates.
Drop-in target list drawSnowForts, drawFireShield, drawShockTowers, drawWormholes, drawSnowStorms, drawWells, drawMeteor, drawGravitalAnomaly, drawStormClouds. Each function in this pass is named so it can be lifted as-is.
